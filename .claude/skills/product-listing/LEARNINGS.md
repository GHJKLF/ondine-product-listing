# Maintaining product-listing

Keep product-specific feedback, attempts, evidence and settings in the operator's external `ondine-operator-state` folder. Do not save them inside this replaceable skill.

Current lessons incorporated after the three September 2026 listings:

- Check actual contents behind size guides and accordions; a successful page request is insufficient.
- Preserve measurement units and all size rows. Flattened text can join inches and centimetres into a wrong number.
- A blocked HTTP page may require rendering. Record the reader that supplies the missing evidence.
- Omit unsupported optional claims; resolve essential identity, price and variant conflicts before the affected write.
- Source model height/UK size must be bound to source evidence; generation does not verify body measurements.
- Generate missing camera views from inspected references, recording inferred geometry separately from facts.
- Internally check original images and upload directly to the owned DRAFT. Final human review precedes activation.
- Record template framing misses and bounded retries honestly. No claimed 4K output or unmeasured token savings.

Historical logs and pre-cleanup copies are retained outside the installable package. Signed fixtures in `tests/` are test evidence, not instructions for new products.
